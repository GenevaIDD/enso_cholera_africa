# analysis/configs

Hand-written configurations only. Everything else is generated from a deploy
YAML by `analysis/utils/deploy_prod_run.R` and is not versioned here.

| Path | Content |
|---|---|
| `deploy/prod_run.yml` | The manuscript run: fit batches, class sweep, lag selection, episode rule, simulator settings, experiments. |
| `deploy/synth_run1.yml` | The same model on the synthetic world (`analysis/00_ingest_synthetic.R`). |
| `results/manuscript*.yml` | The output decisions of phases 09-11 (`manuscript.yml` = the manuscript run; `manuscript_synth.yml` = the synthetic run). |
| `sim_templates/` | Skeletons of the historical / forecast / counterfactual simulator configs (`--stage gen_templates`). |
| `pop_extract/` | Population extraction (02a-02c). |
| `enso_events*.yml` | Registry of past ENSO events (event attribution). |

Generated by the deploy stages (and git-ignored): the fit batches
(`--stage gen_batches`, `utils/make_batch_configs.R`), the simulator templates
(`gen_templates`), the forecast, attribution and hindcast configs and manifests
(`gen_forecast`, `gen_attrib`, `gen_hindcast`) and the event configs (`gen_events`).
